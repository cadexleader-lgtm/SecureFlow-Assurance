PARTIE 1 : EXPIRATION AUTOMATIQUE DES ASSURANCES

1. BASE DE DONNÉES - Table passagers :

Ajoute ces colonnes :
- date_expiration (DATETIME, calculée automatiquement)
- statut_assurance (ENUM: 'actif', 'expire', 'sinistre_en_cours', 'indemnise')

2. BASE DE DONNÉES - Table assurances :

Ajoute cette colonne :
- duree_validite_heures (INTEGER, default 24)

L'assurance peut modifier cette valeur dans ses paramètres (24h, 48h, 72h, etc.)

3. CALCUL AUTOMATIQUE À L'ENREGISTREMENT :

Quand un agent enregistre un passager :
```javascript
const duree_validite_heures = assurance.duree_validite_heures;
const date_enregistrement = new Date();
const date_expiration = new Date(date_enregistrement);
date_expiration.setHours(date_expiration.getHours() + duree_validite_heures);

passager.date_enregistrement = date_enregistrement;
passager.date_expiration = date_expiration;
passager.statut_assurance = "actif";
```

4. CRON JOB - Vérification automatique :

Crée un fichier /cron/check_expirations.js qui s'exécute toutes les heures :
```javascript
const now = new Date();
const passagers_expires = await Passagers.findAll({
  where: {
    statut_assurance: 'actif',
    date_expiration: { [Op.lt]: now }
  }
});

for (const passager of passagers_expires) {
  await passager.update({ statut_assurance: 'expire' });
}
```

Dans server.js, ajoute :
```javascript
const cron = require('node-cron');
cron.schedule('0 * * * *', () => {
  require('./cron/check_expirations');
});
```

5. PAGE VÉRIFICATION QR CODE :

Quand on scanne un QR code, affiche :

SI ACTIF :
- ✅ "ASSURANCE ACTIVE"
- "Valide jusqu'au : [date_expiration]"
- "Temps restant : [calcul en temps réel]"

- Garanties couvertes
- Contacts urgence

SI EXPIRÉ :
- ⚠️ "ASSURANCE EXPIRÉE"
- "Expirée le : [date_expiration]"
- "Depuis : [X jours]"
- "⚠️ Ce passager n'est plus couvert"

Fonction pour calculer temps restant :
```javascript
const diff = date_expiration - new Date();
if (diff <= 0) return "Expiré";
const heures = Math.floor(diff / (1000 * 60 * 60));
const minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
return `${heures}h ${minutes}min`;
```
